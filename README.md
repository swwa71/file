# ملفات — النسخة V5

موقع ثابت لأدوات PDF والصور على GitHub Pages. العمليات تجري على جهاز المستخدم داخل المتصفح؛ لا يوجد خادم لاستقبال الملفات.

## رفع التحديث

الملف ZIP النهائي يحتوي ملفات الموقع **مباشرةً في جذر الأرشيف** (`index.html` و`app.js` وغيرها).

1. افتح مستودع موقعك على GitHub.
2. ارفع **محتويات** الأرشيف إلى موقع ملفات النشر الحالي، واستبدل الملفات المطابقة.
3. لا تغيّر إعدادات GitHub Pages إذا كان الموقع منشورًا ويعمل حاليًا.
4. إذا كان النشر مضبوطًا على `main` و`/(root)`، يجب وضع `index.html` في جذر المستودع. وإذا كان مضبوطًا على `/docs`، ضع الملفات في مجلد `docs`، **دون** إنشاء مجلد `file-main` حولها.
5. بعد النشر، حدّث الصفحة تحديثًا إجباريًا لضمان جلب ملفات التصميم الجديدة.

## ما تغيّر في V5

- تقليص اللوحة العليا والشريط العلوي وقائمة الأدوات على شاشات الكمبيوتر ابتداءً من 860px، لإظهار جميع الأدوات ومساحة الرفع وزر التشغيل في أول شاشة بمقاسات اللابتوب المعتادة.
- الحفاظ على شريط الأدوات الأفقي للجوال مع تحسين التباعد.
- تأثير خفيف مع حركة الماوس، وميلان أقل للبطاقات، وانتقالات أكثر هدوءًا بين الأدوات. تُحترم إعدادات تقليل الحركة في النظام.
- اختصار النصوص دون حذف أي أداة.
- تحسين إصلاح التبديل غير الصحيح للام مع الألف والهمزات (`لا` و`لأ` و`لإ` و`لآ`) بالاعتماد على بيانات المحارف الأصلية عندما يتيحها PDF، مع إبقاء الحركات متصلة بحروفها.
- خياران في أداة PDF إلى نص: **ترتيب ذكي للحروف** افتراضيًا، أو **النص الأصلي من PDF.js** للمقارنة عند الحاجة.

## الأدوات الموجودة

دمج PDF، فصل PDF، استخراج/حذف/تدوير صفحات PDF، ضغط PDF، تحويل الصور إلى PDF، ضغط الصور، استخراج النص من PDF مع تنزيل TXT وWord ونسخه أو طباعته.

## ملاحظات

- استخراج النص يحتاج ملف PDF يملك نصًا قابلًا للتحديد وخرائط خطوط صحيحة. لا يدعم OCR للصفحات المصورة، ولا يمكن لأي خوارزمية إعادة ترتيب إصلاح كل ملفات PDF ذات الترميز المكسور.
- مكتبتا `pdf-lib` و`PDF.js` تُحمّلان من CDN عند أول استخدام؛ قد يلزم الاتصال بالإنترنت. مكتبة `JSZip` مضمنة محليًا.
- الضغط المتوسط والقوي لملفات PDF يحول الصفحات إلى صور وقد يزيل قابلية البحث والروابط. لا يُعد الخيار دون فقدان ضمانًا لتقليل الحجم.

## الملفات

- `index.html`: هيكل الصفحة.
- `styles.css`: الأنماط الأساسية.
- `glass.css`: التصميم الزجاجي والتخطيط المستجيب.
- `background.css` و`bg-office.jpg`: الخلفية.
- `appearance.js`: التأثيرات البصرية والتبديل.
- `app.js`: وظائف الأدوات، بما فيها إصلاح استخراج النص.
- `jszip.min.js`: مكتبة ZIP محلية.
