# ملفات — أدوات مباشرة على GitHub Pages

هذا مشروع موقع خدمات لمعالجة PDF والصور داخل المتصفح. الواجهة الرئيسية تحتوي الأدوات نفسها، وليست صفحة لتنزيل تطبيق.

## نشر الموقع

1. فك الضغط؛ ستجد مجلد `docs` وملفات توضيحية **مباشرة**.
2. من مستودع GitHub `swva71/file` ارفع مجلد `docs` بمحتوياته إلى **جذر المستودع**، حتى يصير المسار `file/docs/index.html`.
3. في `Settings → Pages` اختر `Deploy from a branch` ثم `main` و`/docs`.
4. بعد نجاح عملية النشر، افتح https://swva71.github.io/file/ .

إذا كان المجلد `docs` موجودًا من قبل، استبدل الملفات الموجودة داخله بالملفات الجديدة بدل إنشاء مجلد باسم ZIP أو اسم المشروع.

## الموجود بالموقع

- دمج PDF وترتيب الملفات.
- فصل PDF إلى ملفات صفحات مستقلة أو مجموعات صفحات داخل ZIP.
- استخراج أو حذف أو تدوير صفحات PDF.
- تقليل حجم PDF، مع تنبيه قبل مستويات الضغط التي تحوّل الصفحات إلى صور.
- تجميع الصور وتحويلها إلى PDF.
- ضغط الصور مع التحكم في العرض والجودة.
- استخراج النص الرقمي من PDF وحفظه TXT أو DOCX ونسخه مباشرة أو طباعته.

## تنبيهات تقنية

- معالجة ملفاتك داخل المتصفح؛ موقع المشروع لا يرفعها إلى خادم.
- تُحمَّل مكتبتا `pdf-lib` و`PDF.js` من شبكات توزيع عند أول استخدام، ولذلك يتطلب الاستخدام اتصالًا بالإنترنت في بعض الحالات.
- ليس كل PDF يحفظ النص داخله بصيغة صحيحة؛ الملفات المصورة أو ذات خرائط خطوط غير سليمة قد لا تنتج نصًا دقيقًا.
- تحسين ترتيب نص PDF يعتمد على إحداثيات أجزاء النص، وقد تتطلب المستندات متعددة الأعمدة تصحيحًا يدويًا.
- مستويات ضغط PDF التي تعيد رسم الصفحات كصور قد تفقد الروابط وقابلية تحديد النص، والخيار دون فقدان لا يضمن تصغير كل الملفات.
- الموقع ثابت ولا يحتاج بناء خاص؛ يكفي نسخ مجلد `docs` إلى الفرع `main`.

## طبقات التصميم (مفصولة عن الأدوات)

- `background.css` — الخلفية وحدها (الصورة `bg-office.jpg` + عمق + تضبيب عند التمرير + خيوط ضوء + تعتيم) داخل `.bg-stage`.
- `glass.css` — تصميم الداشبورد الزجاجي فقط (داخل `.dashboard`).
- `appearance.js` — الحركة والتأثيرات (عدسة الأداة النشطة، ضوء الحافة، انتقالات، تحية حسب الوقت، ميلان البطاقات، قصاصات الاحتفال). لا يقرأ بيانات الأدوات.
- `app.js` و`styles.css` — بدون أي تعديل.


## تحديث: PDF إلى نص (عربي) وتخطيط الواجهة
- `app.js`: أداة «PDF إلى نص» تعيد بناء ترتيب الكلمات والاتجاه (عربي/إنجليزي/أرقام) وتصلح حروف «لا/لأ/لإ» التي كان PDF.js يعكسها (السالم ← السلام). ملف Word يُنشأ باتجاه يمين مع فصل الإنجليزي والأرقام.
- `app.js` أيضًا: عند اختيار أداة لا تقفز الصفحة إذا كانت مساحة العمل ظاهرة أصلًا.
- `index.html` + `glass.css`: تخطيط «الاستوديو»: الأدوات في عمود جانبي ثابت ومساحة العمل بجانبها، وعلى الجوال شريط أدوات أفقي.
